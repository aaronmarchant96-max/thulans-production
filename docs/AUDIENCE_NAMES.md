# The Thulan Naming Gate
*Production rule: an audience can hold about six proper nouns at once. This page decides
which names may surface, and which stay texture.*

Companion to `docs/AUDIENCE_PRIMER.md` and `THE_THULANS_LORE_BIBLE_v3.md` §0 (the internal
T1–T4 linguistic tiers). The bible governs what is *true*; this gate governs what is
*heard*.

---

Linguistic T1–T4 provenance is separate from audience-name priority.

## Tier C — Keep out of audience-facing material

Use only in the deep bible, technical specs, or an in-world prop a character does not
translate.

- Long genitive forms in ordinary speech (*Fairgunjis*, *Azghaimis*) — ritual register only.
- Inventory and logistics jargon (*fathom-tare*, *tares*, *casualty allocation*) — allowed
  only if a character explains it in the same line or the meaning is self-evident.
- Machine-asset filenames and version numbers (*v55*, *v54-graviton*) — production only.

---

## The five rules

1. **Six-name ceiling.** No more than six proper nouns before the central rule lands.
2. **One new concept per sentence.** Never introduce two new names in one line.
3. **The deletion test.** A texture name survives only if the scene reads without it.
4. **Marketing is Tier A only.** Trailers, synopsis, and posters use nothing below Tier A.
5. **Nothing read aloud without pronunciation.** Any name in voiceover, song, or trailer
   must carry a guide (see the primer's pronunciation table).

---

## Why this exists

The deep canon is three thousand years wide and deliberately dense — that depth is the
point. The gate does not shrink it. It controls the *rate* at which a viewer is asked to
absorb it, so the first thing they feel is a man trying to save people, not a glossary.
