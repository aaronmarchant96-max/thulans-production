# The Thulans Production

This repository contains the original Thulans literary/cinematic production and documentation for the proposed colony-simulation game **Thulans: Deephearth**. These are related projects, not interchangeable narrative continuities.

## Deephearth game direction (September 18, 2026)

- [Game direction and visual target](docs/DEEPHEARTH_GAME_DIRECTION.md): colony control without a fixed protagonist; Stardew Valley / Dave the Diver-inspired detailed 2D pixel art; Gothic dieselpunk Thulan mountain setting. The approved concept image is an art-direction reference, not implemented game assets.
- [Offline Event Forge prototype plan](docs/DEEPHEARTH_EVENT_FORGE_PLAN.md): proposed constraint-governed narrative generation and test criteria; **not yet verified as implemented**.
- The Varek short story and its ending establish a literary continuity and tonal reference. They do **not** prescribe the game's protagonist, campaign, or outcome.
