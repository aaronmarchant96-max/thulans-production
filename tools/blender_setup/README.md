# Blender MCP setup

Run these scripts inside Blender, using the Text Editor or Blender's `--python` option:

- `install_blender_mcp_inblender.py` installs `/tmp/blender_mcp_addon.zip`, enables the add-on, and saves preferences.
- `enable_blender_mcp.py` enables an already installed add-on and saves preferences.

The scripts retain their original behavior. Historical model builders and renderers are in [`../legacy/blender/`](../legacy/blender/).
